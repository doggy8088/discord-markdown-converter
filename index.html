轉換規則

綜合 Discord 官方文件、社群轉換經驗與 Will 保哥的實戰經驗整理而成。

📋

表格 → 清單

Discord 不支援 Markdown 表格。單列表格轉為「欄位：值」清單；多列表格自動轉為巢狀清單，中文表格使用全形冒號。

✂️

移除分隔線

Discord 不支援 ---、***、___ 等水平分隔線，轉換時整行移除。

🧹

標題前後不加空白行

# 標題與上下行之間不留空白行，避免 Discord 產生多餘間距。

🧺

清單前後不加空白行

清單項目與前後內容緊貼，Discord 才會把它們視為連續的清單區塊。

💬

引用前後不加空白行

> 引用與上下內容緊貼，不插入空白行。

➡️

LaTeX → Emoji / Unicode

Discord 不支援 LaTeX。常見符號自動轉換：$\rightarrow$ → ➡️、$\alpha$ → α、$\infty$ → ∞，支援 90+ 符號。

🔗

移除 file:// 連結

Discord 不支援本地 file:// 協定連結。如 [`src/clients.rs`](file:///path) 會自動去除連結，僅保留文字 `src/clients.rs`。

🔽

H4 以上標題整體降級

Discord 僅支援到 ###（H3）。#### 以上的標題會被降級為 ###，並在轉換統計中記錄警告，可在上方選項關閉。

🛡️

程式碼區塊原封不動

``` 程式碼圍欄內容完全保留：分隔線、空白行、LaTeX、file:// 連結都不會被誤改，確保程式碼安全送達。
